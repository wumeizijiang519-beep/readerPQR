# Windows 11 中文分步操作说明

## 1. 获取并启动程序

**便携版**：打开 GitHub 仓库的 Actions 页，选择 Windows desktop build 中带绿色对勾的运行。在该运行页面下方的 Artifacts 下载 `readerPQR-Windows-x64`。下载通常需要登录 GitHub。解压整个包，双击 `readerPQR.exe`；保留同目录下的 `_internal` 文件夹。若没有绿色构建或没有 Artifact，请用下面的源码启动方式，不要把源码 ZIP 当成已经打包的应用。

**源码版**：安装 Python 3.12 的 Windows 64 位版本，安装时包括 Python Launcher。通过仓库 Code → Download ZIP 下载并解压到可写目录，例如 `D:\Apps\readerPQR`。双击 `start_windows.bat`，等待本次安装命令执行完成后窗口会打开。第一次需要联网安装依赖；以后通常直接启动。不要在 ZIP 内直接运行脚本。

脚本不修改系统 PATH，不需要管理员权限，不将依赖安装到系统 Python。若启动失败，控制台会保留错误信息。

## 2. 配置 AI

打开左侧“AI 设置与术语表”。选择服务预设，填写模型和 API Key。默认智谱示例：

```text
API Base URL：https://open.bigmodel.cn/api/paas/v4
模型名称：glm-4.7-flash
API Key：你自己的智谱密钥
高级 JSON 参数：{"thinking":{"type":"disabled"}}
```

使用其他兼容 Chat Completions 的服务时，选择通用预设，填写服务商给出的 Base URL 与模型名称，并将高级参数设为 `{}` 起步。不是所有接口都支持所有模型参数。遇到 HTTP 400，优先检查模型名称、地址和高级参数。

“测试连接”只发送一句示例英文，用于验证接口和段落 JSON 格式。它可能产生极少量 API 用量。测试成功不代表服务商对长文献的翻译一定完整准确。

核对 API 地址，勾选“我确认当前地址可信，允许将文献文字发送至该 API”。这是授权边界：改变地址后必须重新确认。需要保存密钥时，勾选 Windows DPAPI 选项；不勾选则密钥只在本次进程中保留。

确认“导入 PDF 后自动翻译全文”是否符合你的用量需求，然后保存。

## 3. 导入并阅读

点击“导入 PDF”，或将一个 PDF 拖进窗口。加密 PDF 会要求输入打开密码，不会保存密码。配置完整且允许自动翻译时，导入后会开始逐页处理。

在“逐段对齐”页签中，左侧是原文真实截图，右侧是对应中文。两侧共用一行与一个滚动区域；中文较长时整行增高，而不是覆盖下一段。

在“原页定位”页签中，左侧保留完整 PDF 页面及图表；点击原文文字区域，右侧滚到对应中文段落。点击译文下的“定位原文”则高亮对应原文区域。

左侧导航和上方页码切换页面。搜索框支持原文与已有中文译文，回车定位下一处。原文和译文均提供复制按钮。

如果双栏顺序不理想，在上方切换“按双栏阅读”或“按单栏阅读”重新排序。它是坐标启发式，并不是能理解所有复杂版面的视觉模型。

## 4. 控制翻译用量与恢复

“翻译本页”仅处理当前页。“翻译全文 / 继续”处理全文并跳过匹配的已完成缓存。点击“停止”会取消等待中的网络请求，并保留已经完成的译文。

再次打开同一个 PDF 并使用相同模型、地址、术语表与参数，可读取缓存。模型、术语表或提示词版本变化会使用新缓存，避免混用旧译文；这也意味着新配置可能再次产生费用。

某段翻译失败时，界面明确提示，失败结果不被当成成功译文。再次点击“翻译本页”可重试尚未成功的段落。

## 5. 导出

点击“导出双语”，选择 HTML 或 JSON。HTML 是可离线阅读和打印的文字对照文件；JSON 包括原文、译文、页序和原文坐标，便于后续开发。

需要文字对照版 PDF 时，用 Edge 等浏览器打开 HTML，按 Ctrl+P，选择“另存为 PDF”。这不是原版式中文版：导出的文字对照文件不包含原 PDF 的图表重建，不保证复杂公式排版。核对公式和图表应保留原 PDF。

## 6. 常见问题

**只有原文、没有中文**：检查是否填写密钥、是否对当前地址勾选文字发送许可、是否启用自动翻译。也可以手动点击翻译。

**401 / 403**：检查密钥与对应服务商是否一致，以及账户权限和接口地址。

**429 / 5xx**：限流或服务异常。程序有限次重试后停止；不要反复频繁点击。已有缓存不会丢失。

**连接超时**：检查网络和 API 地址；本机代理环境变量可能影响 HTTP 请求。本程序不会自动修改代理或环境变量。

**提示需要 OCR**：文档没有可提取的文字层，或该页只有少量文字。请先得到可搜索 PDF 再导入。本版本不会假装已翻译扫描页。

**中文和原文行数不同**：这是正常现象。对齐单位是“段落”，不是强制每一行对应；中文会自动换行，左右段落共享同一行容器。

**exe 单独复制后打不开**：把整个下载目录恢复，包括 `_internal`。便携包包含 Qt 与 PDF 运行库，不能只保留一个 exe。

**Windows 提示来源未知**：此版本未代码签名。先核验下载来源、提交记录和成功构建；必要时从源码运行。不要关闭 Defender 或绕过组织安全策略。

## 7. 数据位置与清理

关闭程序后，可查看 `%LOCALAPPDATA%\readerPQR`。

- `settings.json`：接口、术语表及可选 DPAPI 密文。
- `translations.sqlite3`：译文缓存；可能伴随 SQLite 的 `-wal` 和 `-shm` 文件。

删除缓存会失去已有翻译，后续可能重新调用 API。删除设置会重置接口并移除保存的密钥密文。原 PDF 不在这些文件中，也不会因此被删除。
